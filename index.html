실무상 주의사항

  • 포워더를 이용한다고 해서 간접수출이 되는 것은 아님.
  • 수출신고 명의와 실제 거래구조를 기준으로 직접수출 / 간접수출 판단.
  • 간접수출 영세율 적용 시 구매확인서 반드시 확인.
  • 해외 거래 시 Invoice의 제품명, 수량, 금액, HS CODE가 실제 출고내용과 일치하는지 확인.
  • 수출신고 완료 후 수출신고필증 반드시 보관.
  • 외화 입금 시 Invoice 금액과 실제 입금금액 차이 확인.
  • 해외 운송비 부담 주체는 Incoterms 기준 확인.

직접수출

브랜드사가 해외 바이어와 직접 계약하고 브랜드사 명의로 수출을 진행합니다.
거래 구조: 브랜드사 → 해외 바이어

물류 업무 — 필요 자료

  • Commercial Invoice
  • Packing List
  • 제품명 및 영문 제품명
  • HS CODE
  • 제품 수량 및 단가
  • 원산지
  • 해외 바이어 정보(Consignee)
  • Incoterms 조건(EXW / FOB / CIF 등)
  • 필요 시 MSDS
  • 필요 시 원산지증명서(C/O)
신규 제품의 HS CODE는 임의로 확정하지 말고 필요 시 관세사 또는 포워더에 확인

물류 업무 — 진행 절차

해외 바이어 발주 → 결제조건 확인 및 입금 → 제품 출고 준비 → Commercial Invoice / Packing List 작성 → 포워더 또는 관세사 전달 → 수출신고 → 수출신고필증 확인 → 선적 및 해외 배송 → 바이어 배송 완료 확인

포워더나 관세사가 수출신고를 대행하더라도 수출자가 브랜드사 명의인 경우 직접수출에 해당

회계 처리 — 영세율 매출

직접수출은 부가세 영세율(0%) 매출로 처리.
해외 바이어에게는 일반적인 국내 전자세금계산서를 발행하지 않고 수출 관련 증빙을 기준으로 관리

주요 증빙: Commercial Invoice / 수출신고필증 / Packing List / 해외 송금 입금내역 / 거래계약서 또는 PO

회계 처리 — 유의사항

외화로 대금을 수취하는 경우 환율 변동에 따라 환차익 또는 환차손 발생 가능.
수출신고필증의 신고금액, Invoice 금액, 실제 입금금액을 상호 확인하여 관리

수출 관련 증빙은 부가세 영세율 신고 시 필요하므로 반드시 보관

간접수출

국내 무역회사 또는 수출업체에 상품을 공급하고 해당 업체가 해외로 수출합니다.
거래 구조: 브랜드사 → 국내 수출업체 → 해외 바이어

브랜드사의 거래처는 국내 수출업체 / 실제 수출신고 및 해외 통관은 국내 수출업체가 진행 / 원화 거래 시 환차손익 없음

물류 업무 — 국내 수출업체 창고 입고

브랜드사 창고 → 국내 수출업체 → 포워더 → 해외

출고처와 수출업체의 물류 일정 사전 확인

물류 업무 — 브랜드사 창고에서 해외 직배송

브랜드사 창고 → 수출업체 지정 포워더 → 해외

브랜드사 창고에서 바로 해외로 나가더라도 해외 계약 및 수출신고 주체가 국내 수출업체라면 브랜드사 기준 간접수출

회계 처리 — 구매확인서 발급 시

국내 수출업체가 구매확인서를 발급하는 경우 브랜드사는 해당 거래를 영세율 0% 세금계산서로 처리 가능.
구매확인서를 기준으로 간접수출 실적 인정 가능

주요 증빙: 구매확인서 / 영세율 세금계산서 / 거래명세서 / 발주서 또는 계약서 / 입금내역

회계 처리 — 구매확인서 미발급 시

일반 국내 거래로 처리.
예: 공급가액 10,000,000원 + 부가세 1,000,000원 = 총 청구금액 11,000,000원

국내 수출업체와 거래 시 '구매확인서 발급 가능한 거래인지' 사전 확인. 구매확인서 없이 임의로 영세율 세금계산서를 발행하지 않도록 주의
아직 등록된 직납가이드 자료가 없습니다. 자료를 주시면 채워드릴게요.
