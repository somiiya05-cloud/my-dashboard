# 매출 적재 스크립트

이지어드민에서 받은 `매출DB` 파일을 대시보드(Supabase `sales_transactions`)에 올리는 3단계 도구입니다.
파이썬이 없는 PC라 Node 로만 돌아갑니다. Node v24 기준, 외부 패키지가 필요 없습니다.

## 쓰는 법

작업 폴더는 아무 데나 괜찮습니다. 아래는 `260928_매출DB (수기입력포함).xlsx` 예시입니다.

```bash
# 1) 압축 해제 (xlsx 는 사실 zip 입니다)
unzip -o -q "260928_매출DB (수기입력포함).xlsx" -d x28

# 2) 시트 → JSON. 헤더와 데이터 2행을 찍어주니 컬럼 순서를 눈으로 확인하세요
node scripts/sales/xlread.js x28 sheet1.xml s28.json

# 3) JSON → CSV (보정은 여기서 전부 적용됩니다)
node scripts/sales/convert.js s28.json sales_260928.csv out28.json

# 4) Supabase 적재 + 검증. 기대 합계와 날짜를 넘깁니다
node scripts/sales/upload.js out28.json 89347014 2026-09-28
# 여러 날짜가 든 파일이면 날짜를 전부 나열
node scripts/sales/upload.js out.json 396203695 2026-10-02 2026-10-03 2026-10-04 2026-10-05
```

`upload.js` 는 **적재 전에 해당 날짜에 기존 행이 있으면 중단**합니다. 중복 적재 사고를 막는 장치이니
그대로 두세요. 다시 올려야 하면 먼저 그 날짜를 지우고 돌려야 합니다.

## 파일별 역할

| 파일 | 하는 일 |
|---|---|
| `xlread.js` | xlsx 의 `sharedStrings.xml` + `sheet1.xml` 를 직접 파싱해 2차원 배열 JSON 으로 만든다 |
| `convert.js` | 보정 규칙을 적용해 `vendor,brand,product_name,sale_date,quantity,amount` CSV 를 만든다 |
| `upload.js` | 신규 판매처·상품 보고 → 중복 검사 → 500행씩 적재 → 합계 검증 |

### xlread.js 의 핵심

자체닫힘 셀(`<c r="L2" s="3"/>`)을 정확히 건너뛰어야 합니다. 이걸 놓치면 **빈 셀이 다음 셀 값을
끌어와** 컬럼이 통째로 밀립니다. 정규식의 `(\/>|>…<\/c>)` 분기가 그 처리입니다.

### convert.js 가 적용하는 보정

- **브랜드 오타 복구** — 브랜드 칸 값이 `KNOWN_BRANDS` 에 없으면 SKU 접두어로 되살린다.
  실제로 `"글"`(글로리핏), `"ㅏㅃ"`(빠이러스) 같은 값이 들어온 적이 있다.
- **정식 표기 통일** — `라스마`→라이프스타일마트, `폴크`→PORKE, `글로리`→글로리핏
- **판매처명 보정** — `원룸만들기`→원룸만들기(개인), `카카오톡스토어`→(법인), `CONTENTS_DEAL`→공동구매(컨텐츠팀)
- **상품명 별칭** — `고정밴드 4P`→미니멀룸 고정밴드 4p, `자가발열토퍼`→자가발열 토퍼
- **엑셀 날짜 일련번호** — 주문일이 `46301` 같은 숫자면 날짜로 환산 (1899-12-30 기준)
- **`[브랜드] 상품명`** 대괄호를 떼고, 브랜드 칸과 다르면 경고만 띄우고 **브랜드 칸 값을 쓴다**

### 손대야 하는 곳

새 브랜드가 생기면 `KNOWN_BRANDS` 와 `SKU2BRAND` 에, 상품명 변형이 또 나오면 `PRODUCT_ALIAS` 에
한 줄씩 추가하면 됩니다.

**상품명을 합치기 전에는 반드시 원본의 SKU(공급처 옵션명)를 확인하세요.** DB 에는 SKU 컬럼이 없어서
이름만 보면 판단이 안 됩니다. `자가발열토퍼`(MITO002) 와 `자가발열 양면토퍼 NEW`(MITO003) 는 이름이
비슷하지만 **다른 제품**입니다.

## 주의

- `COTO` 접두어는 **코드니처**입니다. 외부 문서에 미니멀룸으로 적힌 것이 있는데 틀렸습니다
  (DB 실측 코드니처 114행 vs 미니멀룸 2행).
- `upload.js` 에 든 Supabase 키는 `index.html` 에 이미 공개된 publishable 키라 새로 노출되는 것은 없습니다.
  service_role 키는 절대 여기 넣지 마세요.
- 영업팀 매출 = 전체에서 `EX` 목록(자사몰·카카오·컨텐츠팀 채널)을 뺀 값입니다. B2B·해외수출은 **포함**입니다.
  목록은 `index.html` 의 `EXCLUDED_FROM_TEAM` 과 맞춰두세요.
